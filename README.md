# Space 3D (Godot 4 Port — Scale 1:1)

Кроссплатформенный порт **Space 3D 1:1** на движке **Godot 4.3+ (Standard, рендер `gl_compatibility`)** — оптимизирован для слабого ПК под Windows, а также для последующего экспорта под **Android (`.apk`)**, **iOS (`.ipa`)** и **Windows (`.exe`)**.

## Быстрый запуск на Windows
1. Скачай **Godot Engine 4.3+ Standard** (НЕ `.NET`) с [godotengine.org](https://godotengine.org/) и распакуй в любую папку.
2. Запусти `Godot_v4...exe` -> **Import** -> выбери файл `d:\Space3dGodot\project.godot` -> **Import & Edit**.
3. Нажми **F5** (Play) для мгновенного запуска прямо на ПК.

## Управление
- **Главное меню:** `ИГРАТЬ`, `НАСТРОЙКИ`, `АВТОРЫ` (со ссылкой на `@xantapers`).
- **Космос (ПК + тач):** `W A S D` или экранный джойстик, зажатая ЛКМ — обзор камерой, колёсико мыши — зум, ползунок тяги, `АВТО`-скорость до `1 млрд c`, орбитальные линии, 3D-метки, FSS-сканер и стыковка к станциям.
- **На поверхности (EVA):** после посадки нажать **«ВЫЙТИ»** (`Space` / кнопка `ПРЫЖОК`, `Shift` / кнопка `СПРИНТ`, реактивный `РАНЕЦ`, `СКАНЕР`, `В КОРАБЛЬ`).
